# AccessStep Dataset Public Data Package

This repository contains the public, de-identified data package for the manuscript:

**AccessStairNet: A Mobile Deep Learning Inspection Tool for Human-Centered Accessibility Assessment of Steps and Thresholds in Elderly Home Environments**

Submission ID: 263362300  
Journal: International Journal of Human-Computer Interaction

## Contents

- `metadata/accessstep_class_distribution.csv`: aggregate class distribution used in the manuscript.
- `metadata/accessstep_annotation_schema.csv`: field-level schema for the underlying frame annotation table.
- `metadata/model_performance_summary.csv`: model-level performance results reported in the manuscript.
- `metadata/mobile_edge_latency_summary.csv`: deployment latency and device summary.
- `DATA_AVAILABILITY_STATEMENT.txt`: manuscript-ready data availability statement.

## Access And Privacy

The full raw image collection was captured in private elderly residential environments. The raw images are therefore not publicly distributed because they may reveal private indoor spaces, layouts, possessions, and other potentially identifying contextual information.

This public package provides the de-identified supporting data required to interpret and reproduce the manuscript-level analyses: annotation codebook, class definitions, aggregate distribution, model-performance summary, and deployment summary. The archived public dataset is available through Zenodo at <https://doi.org/10.5281/zenodo.20151475>.

## Recommended Repository For Journal Resubmission

Taylor & Francis recommends repositories that provide persistent identifiers, preferably DOI, and long-term preservation. GitHub is useful as a code/data mirror, but the final Data Availability Statement should cite the Zenodo DOI: <https://doi.org/10.5281/zenodo.20151475>.
